# Project-FusionLab
Power Fusion Lab is a browser-based superhero power fusion simulation built in pure vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies, zero install.
Fuse abilities, build a team, and fight to survive in a world that fights back. Every run is shaped by 530+ handwritten narrative templates, 12 world events, 14 crisis prompts, and a team chemistry system with 5-dimension scoring. No two playthroughs feel the same.
Features: Power Evolution · Arena Combat (1v1 & 3v3 relay) · Team System · Legacy Encounters · Crisis Prompts · World Events · Full Tutorial · Runs in any browser — local or online.
